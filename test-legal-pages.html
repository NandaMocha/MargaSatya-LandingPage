💡 Troubleshooting Tips

Jika halaman tidak muncul:

  1. Gunakan Web Server: Jangan buka file dengan file:///. Gunakan:
    • Python: python3 -m http.server 8000
    • VS Code: Install extension "Live Server"
  2. Clear Browser Cache: Tekan Ctrl+Shift+R (atau Cmd+Shift+R di Mac)
  3. Check Console: Buka Developer Tools (F12) dan lihat Console untuk error
  4. Verify Path: Pastikan semua file di folder yang sama

Jika styling tidak muncul:

  1. Pastikan styles.css ada di folder yang sama
  2. Check Network tab di Developer Tools untuk melihat apakah CSS ter-load
  3. Pastikan tidak ada AdBlocker yang memblokir CSS
